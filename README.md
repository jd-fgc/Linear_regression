## Concept

The program learns the relationship between mileage (`km`) and price (`price`) from a set of cars, by adjusting two parameters `theta0` and `theta1` according to the hypothesis:

```
estimatePrice(mileage) = theta0 + (theta1 * mileage)
```

The parameters are learned through gradient descent, minimizing the error between the predicted price and the actual price on the training dataset.

## Usage

### Train the model

```bash
python src/train.py --data data.csv
```

The program:
1. reads the dataset (`km,price`)
2. normalizes the data (min-max scaling)
3. runs gradient descent
4. denormalizes `theta0` and `theta1`
5. saves the results to `data/save.csv`

### Predict a price

```bash
python src/predict.py --data data/save.csv
```

The program prompts for a mileage and prints the estimated price:

```
Enter mileage: 100000
Predict price: 6376.42$
```

If `predict.py` is run **without an argument** or **before** `train.py` (theta file not found), `theta0` and `theta1` default to `0` — the program still runs and returns a `0$` prediction.

## How It Works

### Normalization

Raw data (`km` in the order of 10⁴–10⁵, `price` in the order of 10³) have scales too different for a stable gradient descent. Each column is therefore normalized independently (min-max scaling) before training:

```
x_norm = (x - min(x)) / (max(x) - min(x))
```

### Gradient Descent

At each iteration, `theta0` and `theta1` are updated simultaneously according to:

```
tmp_theta0 = learningRate * (1/m) * Σ (estimatePrice(km[i]) - price[i])
tmp_theta1 = learningRate * (1/m) * Σ (estimatePrice(km[i]) - price[i]) * km[i]

theta0 -= tmp_theta0
theta1 -= tmp_theta1
```

### Denormalization

The model is trained on normalized data; `theta0` and `theta1` are then converted back so that `predict.py` can work directly with raw mileage and price values, without having to reprocess user input.

## Dataset

The `data.csv` dataset is expected in the following format:

```csv

240000,3650
139800,3800
...
```

## Bonus

A plotting script (`plot.py`) visualizes the training data and the resulting regression line using `matplotlib`, to visually confirm that the model fits the dataset correctly.

```bash
python src/plot.py --data data.csv --theta data/save.csv
```

It displays:
- a scatter plot of the raw data points (`km`, `price`)
- the regression line computed from the trained `theta0` and `theta1`
